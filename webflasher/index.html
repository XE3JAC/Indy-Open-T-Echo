Ayuda

Antes de comenzar

  1. Usa Chrome o Edge y un cable USB de datos.
  2. Selecciona exactamente tu modelo: T-Echo, T-Echo BME o T-Echo Plus.
  3. Selecciona la banda correcta: 433, 868 o 915 MHz.
  4. No desconectes el equipo durante la copia del firmware.

Instalación en 3 pasos

  1. Pulsa 1. Preparar firmware. El Web Flasher descarga el BIN correcto y genera completamente el UF2 antes de tocar la unidad USB.
  2. Conecta el T-Echo, presiona dos veces rápidamente RESET y, cuando aparezca su unidad de instalación, pulsa 2. Seleccionar T-Echo.
  3. Pulsa 3. Instalar firmware. En este paso sólo se escribe el UF2 que ya estaba preparado.

Al terminar

  1. El T-Echo puede desmontar la unidad USB y reiniciarse automáticamente.
  2. Si Chrome bloquea la escritura directa, pulsa Descargar UF2 y copia ese archivo manualmente a la unidad del T-Echo.
Importante: no instales un firmware de otra variante o banda. Si cambias el modelo o la banda, vuelve a preparar el firmware antes de instalar.
