Ayuda

Antes de comenzar

  1. Usa Chrome o Edge y un cable USB de datos.
  2. Selecciona exactamente tu modelo: T-Echo, T-Echo BME o T-Echo Plus.
  3. Selecciona la banda correcta: 433, 868 o 915 MHz.
  4. La página preparará automáticamente el archivo correcto para tu modelo y banda.

Entrar al bootloader

  1. Conecta el T-Echo por USB.
  2. Presiona dos veces rápidamente el botón RESET.
  3. En la computadora aparecerá una nueva unidad USB correspondiente al modo de instalación del T-Echo.
  4. Déjala abierta; ahí copiarás el archivo UF2 que descargará esta página.

Instalación

  1. Verifica modelo, banda y versión.
  2. Pulsa Preparar firmware. El Web Flasher descargará el BIN sincronizado y generará automáticamente el UF2 correcto.
  3. Copia el archivo .uf2 descargado a la unidad USB que apareció al entrar al bootloader.
  4. Al terminar la copia, el T-Echo puede reiniciarse y la unidad desaparecer. Eso es normal.
Importante: no instales un firmware de otra variante o banda. El Web Flasher selecciona el archivo según el modelo y la banda elegidos; sólo debes copiar el UF2 descargado a la unidad USB del T-Echo.
